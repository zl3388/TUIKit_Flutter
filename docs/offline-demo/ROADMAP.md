# 开发路线图

## 总体顺序

先建立可持续的离线数据与模式基础，再替换用户界面中的云端 Store。不要从单个页面硬编码假数据开始，否则管理编辑、跨页面一致性、重启持久化和后续工作台都会重复返工。

## P0 最新版构建基线

状态：已完成。

交付：

- Flutter 3.44.8 / API 36 / AGP 9 / Gradle 9 / NDK 30 构建链。
- 可验证签名的 Release APK。
- 专属 `dist/android` 输出目录。
- 构建、架构、UX、TODO 和进度文档。

验收：APK 静态元数据、签名及 Room 反射构造函数校验通过；修复包已在 Redmi K80 Pro 完成冷启动与登录页冒烟。

## P1 离线应用骨架

状态：已完成。

目标：应用无云账号即可启动，具有稳定本地数据源和场景包。

工作：

1. 新建 `offline_demo` 分层目录和离线入口。
2. 增加 SQLite 直接依赖、schema 版本与迁移框架。
3. 实现身份、组织、联系人、会话、消息、媒体、通知和公告的首版实体。
4. 实现仓储接口、本地实现和事务性派生字段更新。
5. 实现本地媒体目录、导入复制、缩略图和垃圾清理。
6. 制作最小确定性种子场景；P1 使用 4 个联系人和 4 个会话验证结构，规模化数据留到 P4 性能场景。
7. 启动直接进入默认离线身份，不执行腾讯 SDK 登录和指标上报。
8. 添加 schema、仓储、迁移和冷启动测试。

验收：卸载后首次安装可无网启动；联系人/会话/消息来自 SQLite；修改数据库后重启仍一致。

## P2 核心用户体验

状态：进行中；主导航、我的、通知中心和企业公告已完成。

目标：完成最常用的企业通讯用户端体验。

工作：

1. 离线主导航：消息、通讯录、工作台占位、我的。
2. 会话列表：置顶、免打扰、未读、草稿、搜索和删除。
3. 联系人：组织树、详情、标签、状态、群组和发起聊天。
4. 消息列表与输入：文本、图片、文件、语音占位、视频、通话记录、系统消息、引用和撤回。
5. 本地附件查看：图片预览、视频播放、音频、文档信息与系统打开。
6. 通知中心和企业公告：分类、角标、已读、置顶和详情。
7. 本地发送状态机与确定性自动回复。

验收：核心页面不引用 `atomic_x_core` Store；飞行模式下可完成浏览、发送、附件查看和状态变化。

## P3 管理模式与全量编辑

目标：让测试者从手机端维护所有可见数据。

工作：

1. 隐藏入口、管理口令、会话过期和模式状态条。
2. 联系人、组织、群组、会话、消息、通知、公告和通话记录的就地编辑。
3. 管理控制台的搜索、筛选、批量操作和媒体库。
4. 场景复制、快照、重置、导入和导出。
5. 审计记录、单步撤销与批量恢复。
6. 用户身份切换和不同身份下的会话视角。

验收：用户模式无管理痕迹；管理编辑后切回立即生效；重启保留；破坏性操作可恢复。

## P4 模拟完整度与离线验收

目标：补足看起来像在线产品的动态行为，并证明无服务器依赖。

工作：

1. 来电、去电和通话中页面的离线状态机。
2. 会议创建、邀请、加入、成员状态和结束流程模拟。
3. 自动回复、延迟已读、定时通知和公告发布时间线。
4. 无网络请求监测、飞行模式冷启动和长时间运行测试。
5. 大数据集性能：1000 联系人、300 会话、单会话 10000 消息。
6. TalkBack、字体放大、375px 宽度和长文本验收。

验收：规定场景全程无网络；模拟状态可控可重放；关键列表保持流畅且无错位。

## P5 工作台扩展

目标：加入企业微信类工作台的离线占位体验。

优先顺序：

1. 工作台应用编排与角标。
2. 企业通讯录高级视图。
3. 会议日程与会议详情。
4. 邮件列表、线程、撰写和附件占位。
5. 在线文档列表、详情、协作者和本地编辑占位。
6. 审批、打卡、日程等可配置占位流程。

每个功能先定义演示流程和可编辑数据，再实现页面，禁止只有不可操作的静态入口。

## P6 测试发布完善

目标：形成可重复交付的独立测试产品。

工作：

- 确定应用名、包名、图标、主题和合法自有素材。
- 替换腾讯品牌、示例头像、远程图片和受限表情资源。
- 创建独立测试 keystore，记录证书指纹与轮换方案。
- 配置离线构建变体、版本命名、SHA-256 清单和变更说明。
- 减少无用原生 SDK、ABI 或资源，优化 APK 体积。
- 真机矩阵安装、升级、数据迁移、备份恢复和卸载重装测试。

验收：测试包不与原 Demo 冲突，可重复升级，场景数据可导入导出，发布记录完整。

## 关键决策点

以下信息不阻塞 P1/P2，但必须在 P6 前确认：

- 最终应用名称和 Android applicationId。
- 自有品牌图标、主色和默认场景名称。
- 管理初始口令的交付方式。
- 测试签名文件的保管位置与密码责任人。
- 是否保留直播和美颜演示，或从离线包中移除以控制体积。
