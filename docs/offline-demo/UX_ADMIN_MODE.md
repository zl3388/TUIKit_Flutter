# 管理模式 UX

## 设计原则

- 用户模式应像正常在线企业通讯应用，不出现编辑、模拟或测试提示。
- 管理模式必须明确可辨，避免测试者误把编辑操作当成用户行为。
- 可见内容提供就地编辑，复杂数据和批量操作进入统一管理控制台。
- 编辑结果使用同一份本地数据，切换用户模式后立即生效并跨重启保留。
- 用户模式延续现有应用的克制企业风格；管理状态增加高对比琥珀色标识，不重做成单一主题色界面。

## 隐蔽入口

默认入口位于“设置 > 关于”的版本号：

1. 4 秒内连续点击版本号 7 次。
2. 弹出管理口令底部面板，不在普通界面暴露“管理模式”文字。
3. 首次开发构建若没有 `ADMIN_PIN`，要求测试负责人创建本机口令；发布测试包通过构建参数提供初始口令，并在首次进入后允许修改。
4. 连续输错 5 次后等待 60 秒，避免误触和简单猜测。

该入口只用于防止普通体验者误入，不宣称安全隔离。敏感真实数据不得进入此应用。

## 模式区分

### 用户模式

- 不显示编辑图标、管理浮层、数据来源和模拟控制。
- 启动默认进入最近一次演示身份的消息首页。
- 所有发送、通话、会议和通知行为由本地模拟器响应。

### 管理模式

- 顶部固定 28dp 琥珀色状态条，显示“管理模式”、当前场景、撤销和退出图标。
- 页面右上角只在有明确编辑对象时显示铅笔图标；熟悉图标配 tooltip/语义标签。
- 长按列表项打开上下文操作：编辑、复制、调整状态、删除。
- 底部导航增加“管理”页，进入全量数据控制台。
- 退出管理模式是单击明确命令；切到后台 10 分钟后自动回到用户模式，可在管理设置中调整。

## 两类编辑路径

### 就地编辑

适合测试者看到问题后立即修改：

- 联系人详情：头像、姓名、备注、职位、部门、状态和标签。
- 会话：标题、头像、置顶、免打扰、未读数、最后消息和时间。
- 消息：内容、发送者、方向、时间、状态、附件和引用关系。
- 通知与公告：标题、正文、发布者、范围、时间、已读和置顶。
- 通话记录：类型、方向、结果、开始时间和时长。

保存后返回原页面并保持滚动位置；失败时停留在表单并显示字段级错误。

### 管理控制台

适合结构化和批量编辑：

- 概览：当前身份、场景、数据量、媒体占用和最近操作。
- 人员与组织：树形部门、联系人、群成员和批量导入。
- 会话与消息：筛选、批量时间偏移、状态调整和模板插入。
- 内容中心：通知、公告、图片、文档、音视频和占位资源。
- 模拟规则：自动回复、延迟、来电、会议和通知时间线。
- 场景：新建、复制、快照、重置、导入和导出。
- 应用设置：身份、主题、管理口令、会话超时和功能开关。

移动端不使用宽表格堆叠信息；列表负责扫描，详情页和底部面板负责编辑。批量选择后使用稳定高度的操作栏。

## 表单规范

- 文本、数字、日期、时间、枚举、颜色和媒体分别使用对应控件。
- 二元选项使用开关或复选框，互斥模式使用分段控件或单选组。
- 数字范围使用输入框配步进器；需要直观调整时再使用滑杆。
- 必填项明确标识，失焦时校验，保存按钮显示进行中、成功或失败状态。
- 离开未保存表单前提示保存、放弃或继续编辑。
- 删除、场景重置和批量覆盖必须二次确认，并说明影响数量。
- 头像与媒体选择器支持应用内置资源、本机文件和最近使用，禁止依赖远程 URL。

## 撤销、审计和快照

- 普通字段保存后提供短时 Snackbar 撤销。
- 每次管理写入记录对象、字段、前值、后值和时间。
- 批量操作和场景重置先创建快照，再执行事务。
- 审计页允许查看差异和恢复，但不在用户模式可见。

## 无障碍与稳定性

- 所有自定义点击区域提供 `Semantics` 标签和至少 48dp 触控尺寸。
- 管理色标不能是唯一模式提示，状态条同时显示文字和图标。
- 支持系统字体放大，按钮和列表项尺寸不随动态文本产生布局跳动。
- 表单使用正确键盘类型，TalkBack 顺序与视觉顺序一致。
- 375px 宽度、横竖屏切换、长姓名、长文件名和多语言文本必须无重叠。

## 关键验收流程

1. 用户模式查看联系人，进入隐藏入口并通过口令切换管理模式。
2. 就地修改头像、名称、职位和状态，退出管理模式后原位置立即显示新资料。
3. 在管理控制台插入图片、文件和通话记录，用户模式会话按时间正确排序并可打开本地附件。
4. 修改公告和系统通知的已读/未读状态，角标和列表同步更新。
5. 重启应用后数据仍存在；恢复快照后相关列表、详情和角标一起回退。
